# 次卫生间下一步设计

本轮沿用原墙、门窗洞及现有功能位置，继续细化“外置洗漱＋室内开放淋浴＋蹲便”。不新增淋浴玻璃隔断，不恢复坐便，不改主卫。本文件是方案记录，不是施工定稿。

## 尺寸与依据

- 原图印刷净尺寸为 **1700×1650mm，约2.805㎡**。当前全屋模型为1710×1660mm，各大10mm；放置和通行检查需保留这项差异，不能称为实测尺寸。见 `source-dimension-audit.json` 的 `bath1-width`、`bath1-depth`，以及 `基础尺寸与待确认清单.md`。
- 原图中，门在右上，淋浴在左下，便器在右下，洗手台位于门外右侧。图源：`../floorplan-1-v3/source-plan.png`。原图便器形状不覆盖用户后来确认的蹲便要求。
- 既有用户纠偏已要求蹲便、洗手台外置，并取消完整淋浴隔断。当前实现见 `app.js` 的 `squatToilet()`、`public-bath-details.js` 的 `revisePublicBath()` 末段，以及 `room-facilities.js` 公卫说明。
- 原门洞模型约760mm，铰接端与转向沿用 `plan.js` 的 `doorLeaves.bath1`；窗下缘900mm、窗高1200mm来自 `source-window-schedule.json` 的 W02。磨砂水平移窗仍为待选型方案。

## 布置方向

1. **淋浴和蹲便保持左右分置。** 左后角保留花洒与薄置物架，右后角保留蹲便，入口中间不放落地柜。当前淋浴基准约860×870mm、蹲便外形560×720mm，均为模型包络，实际产品需匹配。
2. **外置洗漱沿用650×400mm方案。** 台盆柜、镜柜使用横移门，保留侧边防溅挡板；延续 `public-dry-zone.js` 的 `integrated` 方案，不重新挤占玄关。
3. **日常储物集中在外置柜。** 室内保留薄洗浴架、毛巾杆和有盖厕纸架。现有600mm宽、约180mm深备用纸柜底高1.88m，不作为老人日常取物位置；是否保留可在视图中比较。
4. **统一暖灰、暖白与低反光金属。** 沿用当前瓷砖与铝扣板表达，暂不为效果图改变材质体系。

## 本轮应完成的具体核对

- 按原门扇扫掠核对进门、关门及走向蹲便和花洒的路径；在无淋浴隔断状态重测，不沿用旧折叠门检查结论。
- 当前 `wetFloor()` 只表达淋浴局部找坡。开放淋浴需要继续核对室内其余地面到排水点的关系及入口挡水；现图尚不能证明水不会流到门外。
- 蹲便盆体下沉195mm只是几何示意。需核对现有沉箱、排污口和所选蹲便尺寸，模型没有确定接管或楼板改动。
- 外置650×400mm台盆需按实际浅盆、存水弯和移门轨道核对柜内净空间，并检查有人洗漱时与换鞋区的关系。
