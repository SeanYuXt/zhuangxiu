# 默认交互界面规范

除非用户明确指定其他主题、模板或布局，所有本地交互式户型模型都采用本规范。界面调整不得修改 `plan.json` 的坐标、面积、墙体或开口。

## 视觉基调

- 使用暖白纸张、浅米灰模型画布和低饱和空间色，形成轻量建筑工作台风格。
- 仅用深橄榄灰作为主强调色；门扇使用暖棕色，窗玻璃使用低饱和蓝绿色。
- 保持模型为主视觉，减少装饰、渐变、阴影和非操作性文案。
- 标题可使用宋体或衬线字体；操作界面使用清晰的无衬线字体。

推荐色值：

| 用途 | 色值 |
| --- | --- |
| 页面背景 | `#f4f1ea` |
| 侧栏背景 | `#fbfaf6` |
| 模型画布 | `#e9e5dc` |
| 分隔线 | `#ddd8cd` |
| 主文字 | `#373731` |
| 次文字 | `#8a877e` |
| 主强调色 | `#5c6255` |
| 强调浅底 | `#e6e9df` |

## 固定布局

桌面端使用“顶部标题 + 三栏工作区”：

1. 顶部栏高约 `72–84px`：左侧显示“真实户型 3D 旋转模型”和简短校准状态；右上角放置分段式视图切换按钮。
2. 左侧栏宽约 `260–300px`：放置空间定位、墙体透明度、面积标签开关和当前建模参数。
3. 中央区域占据剩余空间：仅承载 3D/2D 模型、北向标记、当前空间摘要和操作提示。
4. 右侧栏宽约 `260–300px`：放置校准状态、面积逐项核验、已锁定的关键关系和精度说明。

三栏间距使用 `12–16px`，面板圆角约 `18–22px`。不要把视图切换放在底部悬浮工具条中。

## 左侧空间定位

- 标题为“空间定位”，右侧提供“查看全部”。
- 每个标注空间使用整行按钮，包含色点、房间名、长宽说明和目标面积。
- 点击空间后平滑切换到包含入口的室内广角视角，并同步高亮左侧条目、模型地面和右侧面积行。
- 房间很多时允许侧栏独立滚动，不压缩中央模型画布。
- 墙体透明度默认 `70%`；面积标签默认开启。

## 中央模型区域

- 画布使用浅米灰背景，3D 墙体采用暖白半透明材质，地面使用低饱和暖色区分空间。
- 窗户使用透明蓝绿色，门扇使用暖棕色；不要使用黑色墙体或高饱和材质。
- 面积标签使用暖白小标签、深灰文字和细描边，不使用黑色大标签。
- 右上角显示小型“↑ 北”标记；左下角显示当前空间；右下角显示旋转和缩放提示。
- 透视、俯视、2D 结构图及所有房间视角必须来自同一份验证后的几何。

## 右上角视图切换

- 使用紧凑的分段控制，至少包含“透视”“俯视”“2D”。
- 未选按钮为浅灰透明背景，选中按钮使用 `#5c6255` 深底和暖白文字。
- 切换时使用 `300–800ms` 的平滑相机过渡；俯视必须正北向上且不可东西镜像。

## 右侧核验栏

- 顶部显示“面积校准版”和一句状态说明。
- “面积逐项核验”逐行显示房间名、图纸面积和模型面积，模型值使用强调浅底。
- 明确写出走廊、阳台、飘窗是否计入某个面积总数，避免重复计算。
- 列出对结果有决定意义的门窗、共享墙和连通关系。
- 底部使用深橄榄灰精度说明块，区分发布图精度与施工测量精度。

## 2D 与响应式

- 2D 结构图显示墙厚、开口、门扇方向、北向和实际计算面积，颜色与 3D 空间一致。
- 小屏幕按“中央模型、空间定位、面积核验”顺序纵向排列；顶部视图按钮保持可见。
- 模型区域最小高度约 `460px`，不得因侧栏内容导致水平裁切。

## 禁止项

- 默认使用深色主题。
- 把视图切换放在底部控制坞。
- 使用卡片矩阵、装饰性渐变、多强调色或黑色面积牌。
- 用界面修饰掩盖面积误差、门窗错误或墙体断裂。
- 为追求视觉对称而改变房间比例或镜像南北东西方向。

## 本地交付与验收

- 默认生成本地可运行页面并启动本地浏览器；只有用户明确要求托管或分享链接时才发布到 Sites。
- 至少验证空间定位、查看全部、透视、俯视、2D、透明度和面积标签。
- 检查桌面布局、窄屏布局、浏览器控制台，以及 skill 校验器的最终结果。
